# Progress

Tick a rung when you can pass its self-check **without looking back**. If
you can't, stay on that rung — the next one will assume this one.

## 01 — The terminal: navigation and setup checks

**Self-check:** without notes, can you…

- [ ] Open a terminal and print the current folder with `pwd`?
- [ ] Move into a folder by typing `cd ` (with a space) and **dragging
      the folder** from Finder/Explorer, then prove it with `pwd` / `ls`?
- [ ] Stop a running command with `Ctrl + C`?
- [ ] Run `node --version`, `npm --version`, and `npx --version`, and
      say what a pass vs `command not found` means (including “open a
      new terminal” before reinstalling)?

When all four are yes, mark this rung done:

- [ ] Rung 01 complete

## 02 — Node.js, npm, and installing React

- [ ] Rung 02 complete

## 03 — What React is, and why TypeScript

**Self-check:** without notes, can you…

- [ ] Explain React’s paradigm: describe the UI from data; React
      updates the page (declarative, not a list of DOM orders)?
- [ ] Say what a **component** is, and that React is a **library** not
      a language?
- [ ] Explain that the browser runs **JavaScript**, TypeScript
      **compiles** to JavaScript, and React is the same package in
      either language?
- [ ] Say why **this course** writes React in **TypeScript** (and why
      that is not “a different React”)?

When all four are yes, mark this rung done:

- [ ] Rung 03 complete
